# Research Gap & Academic Contribution

## Project Scope & Contribution

**Title:** Machine Learning Based Phishing URL Detection and Risk Analysis System  
**Specialization:** B.Tech Computer Science (Cyber Security)

### Core Contribution: Explainable Feature Importance & Human-Understandable Threat Scoring

While traditional phishing URL detection systems focus solely on binary classification outputs ("Phishing" vs. "Legitimate"), standard models lack transparency into *why* a given URL is classified as malicious.

### Key Academic Highlights:
1. **Explainable AI (XAI) for Cybersecurity:** Uses Gini Feature Importance to identify top triggering lexical and structural features for each analyzed URL.
2. **Transparent Risk Scoring (0–100 Scale):** Converts raw model output probabilities into a granular risk score accompanied by natural-language threat explanations (e.g., presence of raw IP address, excessive subdomains, missing SSL, target domain spoofing).
3. **Zero Third-Party API Dependency:** Features are extracted locally, providing high detection speed, data privacy, and immunity to external API rate limits or downtime.
